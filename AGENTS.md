# Language

Everything related to code or documentation must be written in English. This includes:

- Identifiers: variables, functions, classes, files, routes and database tables/columns
- Code comments and docstrings
- Commit messages and PR descriptions
- README and all other documentation
- Log messages and error messages in the code

Chat replies to the user can be in whatever language the user writes in.

# Comments

Keep code comments very short. Only comment where the code isn't self-explanatory.
